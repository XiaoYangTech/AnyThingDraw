# AnyThingDraw
[简体中文](README.md) | **English**

[Download](https://draw.yfyw.top) | **[Official Website](https://draw.yfyw.top)**

A screen annotation and presentation assistant for classroom teaching,
forked from the open-source project "Inkeys" with extensive trimming and modifications
tailored to real teaching environments. Written in C++20 for Windows.

</div>

## About This Project

This software is a modified version of [Inkeys](https://github.com/Alan-CRL/Inkeys) by Alan-CRL. Main changes:

- **Feature trimming**: removed modules not used in teaching scenarios (skinning system, random name picker, discontinued Inkeys2 icons, etc.) for a lighter, more focused experience.
- **Synced with upstream**: core features such as drawing and PowerPoint linkage stay aligned with upstream releases.
- **Refined interactions**: touch-device auto detection, eraser clearing logic, PPT toolbar behavior, per-architecture auto update, and other quality-of-life improvements.
- **UI & settings cleanup**: revised interface texts, merged duplicated settings, removed unused entries.

## Download & Requirements

- Official download page: <https://draw.yfyw.top>
- GitHub Releases: <https://github.com/XiaoYangTech/AnyThingDraw/releases>

Installers (NSIS) are provided for 32-bit / 64-bit / ARM64, with in-app auto update.
Requires Windows 7 (RTM, sp0) or later.
