功能特性

✍️

丝滑批注

高性能绘制引擎，笔迹顺滑跟手；画笔、荧光笔、橡皮、图形工具一应俱全，支持冻屏批注与历史撤回。

📽️

PPT 演示助手

自动识别 PowerPoint / WPS 放映，放映中直接批注、翻页、点击页码呼出大纲；切出放映自动收尾，避免残留。

🖥️

教学设备适配

智慧黑板、触摸一体机自动识别并优化触摸书写；可自动隐藏触控光标，橡皮支持点击 / 右键 / 长按快速清空。

⚙️

轻量纯净

面向课堂精简功能，去除冗余入口；设置项合并梳理，界面文本全面优化，上手即用。

⬆️

按架构自动更新

为 32 位 / 64 位 / ARM64 分别提供安装包；软件运行期间静默下载新版本，下次启动时自动完成更新，不打扰课堂。

🛡️

稳定可靠

崩溃恢复、超级置顶、悬浮窗拦截联动等细节打磨；安装包请求管理员权限，默认安装到 Program Files，支持覆盖升级。
